# Домашнее задание: GET-запросы, JSON и параметры запроса

Два скрипта на Python: получение данных из публичного API и запрос с параметрами.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Задание 1 — JSONPlaceholder

```bash
python task1.py
```

Скрипт делает GET-запрос к `https://jsonplaceholder.typicode.com/posts`
(с параметром `_limit=5`), разбирает JSON и выводит заголовок и текст первых
5 постов.

Пример вывода (сокращённо):

```
Получено постов: 5

ID: 1
Заголовок: sunt aut facere repellat provident occaecati excepturi optio reprehenderit
Текст: quia et suscipit
suscipit recusandae consequuntur expedita et cum
...
------------------------------------------------------------
```

## Задание 2 — OpenWeather

```bash
python task2.py
```

Программа спрашивает город, отправляет GET-запрос с параметрами `q`, `appid`,
`units=metric`, `lang=ru` и выводит температуру и описание погоды.

Пример работы:

```
Введите название города: Казань

Погода в городе Казань:
Температура: 7.3 °C (ощущается как 3.9 °C)
Описание: пасмурно
Влажность: 94 %, ветер: 5.86 м/с
```

### Ключ API

Ключ не хранится в коде — он читается из переменной окружения. Сначала
получите бесплатный ключ на [openweathermap.org](https://openweathermap.org/api)
(активируется до 2 часов после регистрации), затем задайте его:

```powershell
$env:OPENWEATHER_API_KEY = "ваш_ключ"          # Windows PowerShell
```

```bash
export OPENWEATHER_API_KEY="ваш_ключ"          # Linux/macOS
```

После этого запускайте скрипт в том же окне терминала. Если переменная не
задана, программа подскажет, что нужно сделать, и завершится без трейсбека.

### Обработка ошибок

Ошибки ключа и неизвестного города API возвращает в теле JSON (поле `cod`),
поэтому скрипт проверяет не только HTTP-статус, но и `cod`. Пример:

```
Введите название города: Ыыыыгород
API вернул ошибку: city not found
```
